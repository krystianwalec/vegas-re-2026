Best free path — Exhibitor Customer Invitations

Exhibitors get complimentary Expo Hall Only passes (allotment by booth size). Attendees can’t claim them from RE+ directly — you need a code/link from the exhibitor.

  1. Pick 3–5 large booths (Tesla, Enphase, Generac, SMA, Sol-Ark, FranklinWH).
  2. Email residential / regional sales (or booth-meeting form) and ask: “Do you have two RE+ 26 Customer Invitation / complimentary Expo Hall codes for Tue Nov 17?”
  3. Register at re-plus.com/register with the invite → typically $0 Expo Hall.
  4. Use one registration if multiple vendors offer invites — don’t create duplicate badges.
  5. Fallback if no invite by ~early November: buy Expo Hall One-Day (Tuesday).
